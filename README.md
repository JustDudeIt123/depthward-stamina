# DepthWard Stamina 3.0.1

Актуальный кандидат публикации: [пакет CurseForge](../release/curseforge-2026-11-10/depthward-stamina/CURSEFORGE.md). Автор — justthekingg. Мод содержит ядро выносливости; интеграции и HUD находятся в Depthward Mod Compat. Сведения о варианте 2.3.0 ниже исторические.

Вариант для ветки Epic Fight. Общий серверный запас обслуживает Epic Fight 20.15.1,
ParCool 3.4.3.2 и Iron's Spells 3.15.4. Shield Expansion и Better Combat не требуются.
Клиент и сервер обновлять вместе; сетевой протокол изменён.

[Правила ресурса, веса, щитов, парирования и кулдаунов](../docs/epic-fight/mechanics.md).
[Сборка и проверки](../docs/epic-fight/testing.md).

Готовый JAR: `build/libs/depthward-stamina-2.3.0-epic.jar`.
В `mods` должна оставаться только одна версия DepthWard Stamina.
